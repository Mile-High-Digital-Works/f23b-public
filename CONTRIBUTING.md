# Contributing

Follow the [code of conduct](CODE_OF_CONDUCT.md) in project discussions.
Report security vulnerabilities privately through the [security policy](SECURITY.md).

Include a description of the problem, reproduction steps, and relevant test
results with a proposed change. [BUILDING.md](BUILDING.md) describes the local
checks and the distinction between offline and in-game validation.

[Open a bug report](https://github.com/Mile-High-Digital-Works/f23b-public/issues/new?template=bug_report.yml).
Reports are most useful with the release version, DCS version, mission, and
steps to reproduce. Remove personal account information and local user paths
from log excerpts before sharing them.

The software is GPL-3.0-or-later with retained file-level MIT grants. Contributions
must have compatible rights and preserve existing attribution. Purchased models,
game assets, SDK files, credentials, and private purchase evidence are not source
contributions. Models and other creative assets have separate license terms.
