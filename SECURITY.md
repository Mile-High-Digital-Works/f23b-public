# Security policy

## Supported versions

Security fixes target the [latest public release](https://github.com/Mile-High-Digital-Works/f23b-public/releases/latest).
Older releases do not receive separate security updates.
Reports about the current source on `main` are also welcome.

This policy covers the F-23B source, installer, and distributed software.
Report vulnerabilities in DCS or other third-party products to their maintainers.

## Report a vulnerability

Use [Report a vulnerability](https://github.com/Mile-High-Digital-Works/f23b-public/security/advisories/new) to send a private report through GitHub.
A GitHub account is required.
Do not publish vulnerability details in an issue, pull request, or forum post.

Include these details where possible:

- The affected release or source commit.
- Your Windows and DCS versions, if relevant.
- Steps to reproduce the problem in an isolated test environment.
- The security impact and any suggested correction.
- Relevant logs or a minimal example with personal information removed.

Do not include passwords, access tokens, account details, or third-party game files.
Test only systems and files that you own or have permission to test.

The maintainer will use the private report to discuss findings and possible fixes.
Response and resolution times depend on maintainer availability. No fixed response time is guaranteed.
Coordinate public disclosure through the private report so users can receive a correction or mitigation first.

For installation problems or aircraft bugs without a security impact, use the
[bug-report form](https://github.com/Mile-High-Digital-Works/f23b-public/issues/new?template=bug_report.yml).
