# F-23B v1.5.1

[Download v1.5.1](https://github.com/Mile-High-Digital-Works/f23b-public/releases/tag/v1.5.1).

Choose **F-23B-v1.5.1.zip** for manual installation or **F-23B-v1.5.1-Setup.exe** for automatic installation.
Both install identical aircraft, weapons, ten liveries and documentation.

Requires Windows and an installed, activated **DCS: F/A-18C Hornet**.
The weapon and radar connection supports **DCS 2.9.31.29434**.
**Multiplayer is untested. VR is untested.**
